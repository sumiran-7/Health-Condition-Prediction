# 🩺 Health Condition Prediction

An end-to-end Machine Learning project that predicts an individual's health condition using lifestyle and physiological data.

## 🎯 Project Objectives

- Perform comprehensive data cleaning
- Conduct advanced exploratory data analysis (EDA)
- Engineer meaningful features
- Train and compare multiple machine learning models
- Interpret model predictions
- Deploy the final model as a web application
